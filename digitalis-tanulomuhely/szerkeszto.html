Biztonságos belépés

A tulajdonosi GitHub-fiókhoz tartozó, csak az abece-kaland tárolóra érvényes szerkesztési kulcs szükséges. A kulcsot nem tároljuk, és kizárólag a GitHub API-nak küldjük.

Szerkesztési kulcs létrehozása

Repository access: Only select repositories → abece-kaland. Repository permissions: Contents → Read and write.

A PDF-eket, Google-űrlapokat, Wordwall-játékokat és alkalmazásokat a hivatkozásukkal add hozzá. A mentés a közös tanulói katalógust frissíti.
